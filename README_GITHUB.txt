MANUAL APS 3.0 — FRONTEND PUBLICO (SEM BANCO CLINICO)

1) PRIMEIRO, implante o backend privado do pacote separado.
2) Abra config.js e substitua window.APS_API_BASE pela URL REAL do Worker Cloudflare.
3) Publique SOMENTE os arquivos deste frontend na raiz de um repositorio publico GitHub Pages.
4) Configure ALLOWED_ORIGIN no backend como https://SEU_USUARIO.github.io (sem caminho do repositorio).
5) Abra DPOC (Manutencao), Anemia na Gestacao e Faringoamigdalite para validar.
6) NUNCA publique os arquivos .sql nem o ZIP backend em repositorio publico.

Obs.: Busca por titulo/sinonimos funciona localmente; texto completo e condutas dependem de internet.
A logica das calculadoras permanece no JavaScript publico; qualquer regra presente nesse codigo
pode ser inspecionada. Isso e uma protecao contra download integral do banco, nao DRM infalivel.
